- Очки Ресурса -> Очки Крови

# 📄 ./Механики/Прогрессия/Черты/Ярость.md


| Теги             | Что?                                |
| ---------------- | ----------------------------------- |
| Нужно            |                                     |
| Исключение Нужно |                                     |
| Блок             | Любая черта заменяющая Очки Ресурса |
| Исключение Блок  |                                     |
Заменяет: 
- Очки Ресурса -> Очки Ярости
	Очки Ярости накапливаются. Каждый нанесенный урон +1 очков Ярости.
	Если за раунд не был нанесен урон или получен урон, все Очки Ярости сбрасываются.
Дает: 
- Активная: Впасть в Ярость
	Вы впадаете в Ярость. Вы тратите все накопленные Очки Ярости. Урон Ближнего Боя + потраченные Очки Ярости.
	Пока Ярость активна, очки Ярости не копятся.
	Если за раунд не был нанесен урон или получен урон, Ярость выключается.
	Атака по вам с приемуществом.

## Черта

| Теги             | Что?                                                                             |
| ---------------- | -------------------------------------------------------------------------------- |
| Нужно            | То что нужно для получения и использование черты                                 |
| Исключение Нужно | То что блокирует получения и использование черту, если условие Нужно выполняется |
| Блок             | То что блокирует получение и использование черты                                 |
| Исключение Блок  | То что позволяет получить и использовать черту, если условие Блок выполняется    |
Дает - Дает что-то
Убирает - Убирает что-то
Заменяет - Заменяет что-то на что-то
Выбрать - Нужно что-то выбрать из предложенного.

Пассивная - То что не требует активного действия и действует постоянно
Активная - Для использования нужно активное действие
