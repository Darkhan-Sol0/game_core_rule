| Блок             | Любая черта заменяющая Очки Ресурса |
| Исключение Блок  |                                     |
Заменяет: 
- Очки Ресурса -> Очки Маны
	Мана восполняется полностью после отдыха.
Дает: 
- Пассивная: Магическое Знание
	Можно кастовать заклинание 0 Уровня.
	Можно использовать Свитки Заклинаний
- Активная: Поглощение Эфира
	Можно поглотить Кристалл Эфира для восполнение Очков Маны.
